# 冒頭3秒フック公式集（事実ベース・実証パターン優先）

`agents/hook-generator.mjs` が参照する **フック生成テンプレ**。
generic な煽りパターンではなく、**実証されたバズ動画のタイトル形式** に絞り込み。

## FOMO 拡張公式 (F06-F10) — 即時購入を焦らせる

> 景表法注意: 「絶対値上げ」「残り3個」など虚偽の数字・期間は使用禁止。
> 主観表現 (「かも」「だろう」「感じ」) + 損失喚起で攻める。

### F06: 損失予告「買い逃したら後悔」型 ⚡FOMO最強

|---|---|

| 例 | • 今買わないと一生損するAmazon神品5選<br>• 買い逃したら後悔するTikTok爆売れTOP3 |

## FOMO の重ね方 (実証パターン)

複数の FOMO 要素を **1動画に重ねる** と効果が積算する:

| 配置 | 要素 | 例 |
|---|---|---|
| Hook | 希少性 + 損失 | 「99%は知らない、今買い逃すと一生損する」 |
| Rank 字幕 | 群衆プルーフ | 「既に1万人が買ってる」「リピ買い続出」 |
| 価格表示 | 値上げ予告 | 「※もうすぐ値上げかも」 |
| CTA | 時間 + 損失 | 「今すぐプロフから」「明日には間に合わないかも」 |

→ **動画1本に最低3個の FOMO 要素** を入れるのが目安。

## 強いフックの3条件 (実証された)

1. **数字を含む** (「3年」「3,000円」「5選」「100万再生」)
2. **実体験 or 損失** (「リピ買い」「買って後悔」「悩んだ」)
3. **完結が見える** (「3選」「TOP3」「これで解決」)

## NG ワード (アルゴリズム評価↓)

- 「すごい」「やばい」「最強」 (具体性0)
- 「絶対」「100%」「永久に」 (景表法リスク)
- 「神」を超頻度使用 (陳腐化、ただし「神アイテム」TOP3型では1回限り OK)
- 「拡散希望」「フォロバ100」 (スパム判定)

## A/B テスト指針

同じ商品リストで **3つのフック** を作って、動画は1本だけ作る。  
キャプ 1行目だけ差し替えて、3回投稿（1週空ける）→ 一番反応がいいものを採用。
