# クロスプラットフォーム展開（1動画→3プラットフォーム）

同じ MP4 を **TikTok / YouTube Shorts / Instagram Reels** に投稿して露出を3倍にする。Linktree は共通。

## 仕様適合性（1080x1920 / 30秒）

| プラットフォーム | アスペクト比 | 最長 | 当パイプラインの動画 |
|---|---|---|---|
| TikTok | 9:16 | 10分（推奨60秒以下） | ✅ 30秒 |
| YouTube Shorts | 9:16 | 60秒 | ✅ 30秒 |
| Instagram Reels | 9:16 | 90秒 | ✅ 30秒 |

→ そのままアップロード可。

## 投稿のコツ（プラットフォーム別差分）

### TikTok
- **冒頭3秒** が命。フックの強さでアルゴリズム勝敗が決まる
- ハッシュタグ: 大4 + 中3 + 小3 = 10個
- 投稿後すぐ自分でコメントしてピン留め
- BGM はトレンド音源（プラットフォーム内）を後乗せ推奨

### YouTube Shorts
- **タイトル** が SEO 重要。検索キーワードを含める
  - 例: `Amazonで爆売れ｜自己啓発グッズTOP5【2026年】#shorts`
- 概要欄に **Linktree URL + 個別 Amazon アフィリ URL** を貼れる（TikTok と違って longリンクが効く）
- ハッシュタグは説明欄に 3-5個
- `#shorts` を必ず入れる（Shorts 棚に乗る条件）

### Instagram Reels
- ハッシュタグ: 5-10個
- キャプションは 125文字までが表示推奨
- Bio リンクは「Linktree URL のみ」（プロフィール欄から）
- ストーリーズで Reels を再シェアすると拡散

## 統一すべき / 変えるべきもの

| 要素 | TikTok | YouTube Shorts | Instagram Reels |
|---|---|---|---|
| 動画ファイル | ✅ 同じ | ✅ 同じ | ✅ 同じ |
| キャプション | 短め・煽り | SEO意識・長め | 中間・絵文字多め |
| ハッシュタグ | 10個 | 3-5個 | 5-10個 |
| Bio リンク | 1つ（Linktree） | 概要欄に複数可 | 1つ（Linktree） |
| ピン留めコメント | あり | なし | なし |
| 投稿時間 | 21-23時 | 19-21時 | 20-22時 |

## キャプ・ハッシュ テンプレ

`posting-kit.md` のキャプを基本に、プラットフォーム別に微調整:

### TikTok 用
```
自己啓発グッズ買うならこの5択。
5位はマジで脳のため。1位は読んでないと損

▼Amazon全部プロフリンク
#自己啓発 #Amazon #自己啓発本 #おすすめガジェット #買ってよかった #ライフハック #朝活 #生産性 #ベストセラー #本紹介
```

### YouTube Shorts 用
```
タイトル: Amazon自己啓発TOP5｜知らないと損する2026年ベストセラー #shorts

説明欄:
Amazonで本気で売れてる自己啓発5選を紹介。
詳細は概要欄のリンクから

▼まとめサイト
https://your-handle.github.io/

▼個別リンク
1位 7つの習慣: https://amzn.to/xxxxx
2位 Kindle: https://amzn.to/xxxxx
（以下省略）

#shorts #自己啓発 #Amazon #ベストセラー

※当チャンネルはAmazonアソシエイト・プログラムの参加者です
```

### Instagram Reels 用
```
自己啓発グッズを買うなら絶対にこの5択
詳細はプロフリンクから 

#自己啓発 #Amazon #自己啓発本 #ライフハック #朝活 #自己投資 #ベストセラー
```

## 投稿のタイミング戦略

**初週**: 3プラットフォーム同時投稿（同じ動画ファイル）
- これで「どこが一番フィットするか」が見える

**2週目以降**: バズった先 1〜2 個に絞って投稿頻度を上げる
- 全プラットフォーム同時並行は管理がきつい
- 「メイン1個 + サブ1個」が現実的

**Amazon Associates の URL 登録**: TikTok / YouTube / IG の URL を全部 Amazon Associates の管理画面に登録（規約必須、未登録のサイトでアフィリ URL を使うと契約解除リスク）

## ファイルアップロードの実務

レンダ済み MP4 をスマホに転送して投稿:
- **AirDrop / Google Photos / Dropbox** いずれかで `output/*.mp4` をスマホへ
- TikTok アプリで投稿（PC版は機能制限あり、スマホアプリ推奨）
- YouTube Shorts は YouTube Studio から PC でアップ可（タイトル・説明編集が楽）
- Instagram Reels はアプリのみ（PC からは投稿不可）

## メトリクス追跡

Amazon Associates のレポート画面でクリック数・売上が見える。**プラットフォーム別に分けて見たい場合**:
- URL に `?ascsubtag=tiktok` のような subtag を付ければ計測可能（無料）
- `build-linktree.mjs` を改造して 3バージョンの output 出すことも可（必要なら言って）
