# Amazon アフィリエイト需要マップ（2026年）

紹介料率 × 購入頻度 × 動画適性 を掛け合わせた **収益期待値マトリクス**。`agents/product-picker.mjs` が商品選定で参照する。

## ジャンル別の動画映え分析

| ジャンル | 動画適性 | 理由 |
|---|---|---|
| **本（Kindle/紙）** | ★★★★ | 表紙が映える、Kindleは画面 UI も使える |
| **ガジェット小物** | ★★★★★ | 動きが見せられる（ポモドーロタイマー回る、デスクライト光る等） |
| **食品（粉末系）** | ★★★ | 静止画でも色とパッケージで映える |
| **文房具（手帳）** | ★★★★ | ページめくり動画が刺さる |
| **服・ジュエリー** | ★★ | モデル着用が必要、テンプレ化しにくい |
| **家電** | ★★★ | ベンチマーク数字が映える |
| **カメラ** | ★★ | 単価高すぎ、購入頻度低い |
| **PC本体** | ★ | 衝動買い圏外 |

## 推奨ジャンル戦略（このプロジェクト）

### Tier 1（主軸 / 毎週投稿）
- **自己啓発本（Kindle 8% / 紙 5%）**: テンプレ化最高、CVR 高い
- **習慣化グッズ（手帳・タイマー）**: 動画映え、感情訴求できる

### Tier 2（補強 / 月2-3本）
- **食品（プロテイン・コーヒー・健康食品）**: 8% 高料率、購入頻度高
- **健康ガジェット（睡眠改善等）**: 体感ベネフィットを訴えやすい

### Tier 3（差し込み / 月1本）
- **高単価ガジェット（Kindle Paperwhite、ノイキャンヘッドホン等）**: 1個 ¥1,000 報酬狙い
- **季節商品**: ボーナス時期、新生活、ブラックフライデー

### 避けるべきジャンル
- **ゲーム機本体・PC**: 紹介料 0.5% で報酬上限¥1,000 すら届かない
- **服・ジュエリー**: Amazon での購入頻度が低い、動画適性が低い
- **医薬品・健康効果を謳う商品**: 景表法・薬機法リスク

## ニッチ深掘り候補（成功事例から逆算）

### 副業・在宅ワーク系
- **モバイルモニター** (¥15,000-25,000, 家電 2%): 副業層の購入頻度高
- **ノートPCスタンド**: ¥3,000-5,000、手元映像が映える
- **ワイヤレスキーボード**: Logicool MX Keys シリーズが定番

### 朝活・睡眠系
- **光目覚まし時計**: ¥10,000前後、画面で光るのが映える
- **遮光カーテン**: テンション低いが購入率高い
- **加重ブランケット**: 体感系で訴求

### 学習系
- **電子辞書、シャドーイング本**: 8%
- **Bluetoothイヤホン**: 学習用の選定
- **ホワイトボード（語彙書出し用）**: 動画適性高

### ガジェット系（動画映え）
- **デスクライト（BenQ ScreenBar）**: 光るのが映える
- **メカニカルキーボード**: 打鍵音が刺さる
- **モバイルバッテリー（Anker）**: 容量数字が映える

## アフィリエイト URL の規約まとめ

- ✅ **OK**: TikTok / YouTube / Instagram / 個人ブログ / Linktree（事前登録必須）
- ✅ **OK**: 個別 ASIN URL（`https://www.amazon.co.jp/dp/<ASIN>?tag=<id>`）
- ✅ **OK**: Storefront URL（Influencer Program 通過後）
- ✅ **OK**: 短縮 URL（Amazon 公式 `amzn.to` のみ）
- ❌ **NG**: bit.ly などの第三者短縮 URL（規約改訂 2026-04 以降明示）
- ❌ **NG**: 自己購入・家族購入による 3件達成
- ❌ **NG**: PR 表記なしの投稿
- ❌ **NG**: 「絶対痩せる」「100%稼げる」断定表現
