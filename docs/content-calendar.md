## 各週のストーリー型 主軸商品

ストーリー型はランキング型の **1位 or 3位** を主軸にして、感情訴求 → 商品 で訴える。
ナレーション原稿は `scripts/generate-story-tts.sh` を週ごとに編集して再生成。

## 量産フロー（1週分 = 2本 = ~1時間）

```
月曜の朝:
  1. data/products.json の products を Week N に書き換え
  2. node scripts/swap-products.mjs       # index.html 反映
  3. bash scripts/new-video.sh week-N-rank   # ランキング型レンダ

水曜の朝:
  1. scripts/generate-story-tts.sh のセリフを Week N に書き換え
  2. bash scripts/generate-story-tts.sh   # ストーリー用 TTS 再生成
  3. story-mode/index.html の商品名・価格・Before/After 数字を編集
  4. npx hyperframes render story-mode/index.html --output output/week-N-story.mp4

月曜21時 + 木曜21時: TikTok 投稿（posting-kit.md のキャプ使用）
```

## 補足

- **トレンドが強い週はそちらに寄せる**（例: Black Friday 直前は「Amazon ブラックフライデー 買うべき TOP5」を Week N の代わりに差し込む）
- **季節商品**（夏: ハンディファン、冬: 加湿器）は通常週を 1〜2本差し替えて挿入
- **バズった週のテーマ**は翌週も類似テーマで横展開（例: Week 5「副業」が伸びたら Week 6 で「副業の続編」）
