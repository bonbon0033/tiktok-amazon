## 即量産モデル 8つ（事例ベース・コピペで即動画化）

`agents/hook-generator.mjs` の `pattern` 引数で切替。各モデルは実バズ動画から逆算した秒数別構造を持つ。

### ▼ パターン①: ランキング系（画面画像ベース・スクロール動画）

#### モデル 1: シンプル爆売れ TOP5（15-20秒・最も再現性高）

| 秒 | シーン | テキスト・画像 |
|---|---|---|
| 0-3 | Hook | Amazon検索画面 + 「Amazonで今爆売れ！自己啓発グッズTOP5【知らないと損】」大文字 |
| 3-15 | 本編 | ランキングスクロール 1位→5位 各2秒。商品ページキャプチャ + BSR + 星4.5以上 + 価格 |
| 15-20 | CTA | 全商品一覧 + 「プロフリンクにまとめた！どれが欲しい？コメントで」 |

- **実例**: Amazon プライムデーおすすめ5選動画 (3万ビュー超)、Amazon おすすめ5選動画 (@gakulange類似)
- **バズ理由**: 視覚的信頼感、即「買いたい」喚起
- **実装**: 既存 `index.html` (TOP5 ランキング型) 相当 (30秒、これを 20秒に短縮するなら data-duration 調整)
- **Claude プロンプト**: `pattern=ranking-top5` で hook-generator 呼出

#### モデル 2: 芸能人/有名人風「○○が使ってる」ランキング（20-30秒）

| 秒 | シーン | テキスト・画像 |
|---|---|---|
| 0-3 | Hook | 派手テキスト「芸能人も愛用！Amazon自己啓発グッズランキングTOP5」 |
| 3-25 | 本編 | 各商品に「芸能人風」オーバーレイ + 商品 + ★ + 「月収アップに繋がったレビュー」抜粋 |
| 25-30 | CTA | 「これで私も生産性2倍！プロフから今すぐ」 |

- **実例**: 「有名人がハマってる神グッズ」系
- **バズ理由**: 憧れ + FOMO（取り残される恐怖）
- **Claude プロンプト**: `pattern=ranking-influencer`

#### モデル 3: ニッチ特化「低認知高評価」ランキング（25秒）

| 秒 | シーン | テキスト・画像 |
|---|---|---|
| 0-3 | Hook | 「Amazonで隠れ爆売れ！知る人ぞ知る自己啓発グッズTOP5」 |
| 3-22 | 本編 | 画面キャプチャ + 「レビュー抜粋」テキスト |
| 22-25 | CTA | 「プロフから即チェック」 |

- **実例**: 低単価ニッチ商品ランキング（月数十万再生事例）
- **バズ理由**: 競合少なく成約率高、希少性
- **Claude プロンプト**: `pattern=ranking-niche`

### 量産運用 Tips

- **交互投稿**: 週3回ランキング型 + 週2回スライド型 → アルゴリズム最適化
- **商品選び**: 自己啓発 (手帳・タイマー・本・ノート)、★4.5+、¥1,000-¥5,000
- **大量生成**: `for pattern in ranking-top5 slide-life-change slide-routine; do node agents/hook-generator.mjs <theme> $pattern; done`
- **初週は再生重視、2週目から CVR 確認**（Linktree 最適化）

## 真似すべき主流パターン 3つ

### Pattern A: TOP3 価格縛り型 ← **最優先で実装すべき**

代表的タイトル:
- 「Amazonで3,000円以下で買える神アイテム3選」
- 「100均で買える便利グッズ TOP3」
- 「5,000円以下で人生変わる Amazon商品」

**なぜ刺さるか**:
1. **数字 (価格)** が冒頭に出る → アルゴリズム評価↑
2. **TOP3** → 5より深掘り可（1商品10秒取れる）
3. **価格縛り** → 衝動買い帯にユーザー想定が固定
4. **コスパ訴求** → 信頼感↑、CVR↑

**構造 (35秒)**:
| 秒 | シーン | 内容 |
|---|---|---|
| 0-3 | Hook | 「¥3,000以下しばり」「Amazon神アイテム TOP3」を爆発出現 |
| 3-13 | 3位 (10秒) | 商品画像 → 価格デカ → 「①リピ理由」字幕 → 「②もう一つの理由」 |
| 13-23 | 2位 (10秒) | 同上 |
| 23-32 | 1位 (9秒) | 同上 + 「ガチで人生変わる」強調 |
| 32-35 | CTA | プロフリンク誘導 |

**字幕設計**:
- 数字 (¥1,980, ★4.5) を **画面いっぱい** に
- 「①」「②」の手順番号を必ず使う (リサーチで「3ステップで完成」型字幕が刺さると判明)

→ 実装: `compositions-roots/top3-price.html`

### Pattern B: 実体験「リピ買い」型

代表的タイトル:
- 「私が3年リピ買いしてるAmazonアイテム5選」
- 「Amazonで何回も買い直した便利グッズ」
- 「リピ買いしすぎてヤバいAmazon商品」

**なぜ刺さるか**:
1. **「3年」「リピ買い」**の実体験ワードでソーシャルプルーフ
2. 「私が使ってる」= 信頼感↑、断定回避
3. 5商品で関連性ある場合、保存率↑（「全部買おう」需要）

**構造 (35秒)**:
| 秒 | シーン | 内容 |
|---|---|---|
| 0-3 | Hook | 「3年リピ買いしてる」「Amazon の神アイテム5選」 |
| 3-9 | #5 (6秒) | 商品 + 「リピ買い回数」「使用期間」 |
| 9-15 | #4 | 同上 |
| 15-21 | #3 | 同上 |
| 21-27 | #2 | 同上 |
| 27-32 | #1 (5秒) | 同上 (短め、すでに溜まった期待で十分) |
| 32-35 | CTA | プロフリンク |

→ 既存 `index.html` (ランキング型) のフックを「リピ買い」型に改修すれば近似可。

### Pattern C: 課題解決ストーリー型

代表的タイトル:
- 「3年悩んだ朝起きれない問題、これで解決した」
- 「集中力ゼロだった私がコレ買って変わった話」

**なぜ刺さるか**:
1. **共感** (「私もそう」需要)
2. **ビフォーアフター数字** で保存率↑
3. **「1商品深掘り」で CVR 最高**

**構造 (35秒)**:
| 秒 | シーン | 内容 |
|---|---|---|
| 0-3 | Hook | 「3年悩んでた○○問題」 |
| 3-10 | Problem | 失敗の数字 (再生数0、月収¥0 等) |
| 10-18 | Realization | 「気づいた」テキスト + 原因の言語化 |
| 18-30 | Solution | 商品 + Before / After + 期間 |
| 30-35 | CTA | プロフリンク |

→ 実装済み: `story-mode/index.html` (旧 index-story.html)。 ただし30秒 → 35秒に延長すべき。

## 編集の鉄則 (事実ベース)

### カット切替

- **音楽のビート同期** (CapCut / Filmora の自動ビート検出を使う)
- 平均間隔: **1-2秒** （3秒超は離脱率↑）
- 30秒動画なら **15-25カット**

### 字幕

- 必須 (40-60% が音オフ視聴)
- **価格・★・レビュー数** は数字だけ巨大表示
- **「①②③」「STEP1/2/3」** など順序を明示
- 色は3色まで (このプロジェクトは lime / cyan / red 固定)
- フォント: Inter Bold + Anton (数字専用)

### 効果音 (SE)

- 冒頭にピン!or 引き音 (ASMR 的)
- ランキング切替に「ポン」音
- 価格表示に「キラーン」音
- 出展: TikTok 内蔵 SE or 効果音ラボ (フリー)

### BGM

- ランキング型 → TikTok トレンド音源を後乗せ (BGM 焼込みなし)
- ストーリー型 → 焼込み BGM (DOVA-SYNDROME の lo-fi)
- 焼込む場合の音量: 0.18-0.25 (ナレが主)

### エフェクト

- **最大3種、各4秒以内**
- 使うのは: フラッシュ・ズーム (in/out)・カットイン
- これ以上は陳腐化
